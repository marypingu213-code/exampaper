# 教室畫面同步（學生掃 QR Code 看老師畫面）

老師電腦（接大電視的筆電）的畫面，即時同步到學生手機。學生不用裝 App，掃 QR Code 用瀏覽器就能看，還可以兩指放大看考卷細節。

## 第一次準備（只要做一次）
1. 到 https://nodejs.org 下載安裝 **Node.js（LTS 版）**
2. 下載這個 `screen-share` 資料夾到老師電腦

## 上課時使用
1. 老師電腦和學生手機連上**同一個 Wi-Fi**
2. 啟動：
   - Windows：雙擊 `start-windows.bat`（第一次 Windows 防火牆跳出提示時，請按「允許存取」）
   - Mac：雙擊 `start-mac.command`
3. 瀏覽器會自動開啟「老師控制台」（`http://localhost:8080/host`，請用 Chrome 或 Edge）
4. 按「🔍 在大螢幕放大顯示 QR Code」，學生用手機相機掃描
5. 按「▶ 開始分享畫面」，選擇要分享的整個螢幕或某個視窗（例如考卷、PowerPoint）
6. 可隨時按「⏸ 暫停」（學生畫面停在當下）或「■ 停止」

## 學生作答（選擇題 / 圈選題）
學生第一次加入時會輸入**名字或座號**（之後會記住）。在控制台「③ 學生作答」：
- **🔢 出選擇題**：學生手機下方出現 1、2、3、4 大按鈕（選項數可設 2～6）。老師看得到每個選項幾人、是誰選的；按「設為答案並公布」後，學生手機會顯示答對或正確答案。
- **⭕ 出圈選題**：學生手機上的畫面會定格，學生用手指在題目上**把答案圈起來**再送出（有紅筆、藍筆、復原、清除）。老師看到每個人圈的結果，可以逐一按 ✓ / ✗，學生手機會收到「答對了」。
- **📥 收卷**：停止作答（可再開放）。「還沒作答」的名單會即時顯示。
- **📺 大螢幕顯示結果**：全螢幕顯示統計或大家的作答，可勾選「隱藏姓名」，避免答錯的同學尷尬。
- **✖ 結束作答**：學生回到一般看畫面模式。

## 功能
- 學生端只能「看」，無法控制老師電腦；老師控制台只能在老師電腦本機開啟
- 畫面沒變動時自動降低傳輸量，全班一起連也不容易卡
- 可調整畫質與更新速度；網路慢的學生會自動跳過舊畫面，不會越來越延遲
- 斷線會自動重新連線；晚加入的學生會立刻看到目前畫面

## 常見問題
- **學生掃了打不開**：確認手機不是用行動網路、而是連教室 Wi-Fi；有些學校 Wi-Fi 會隔離裝置（AP 隔離），可改用老師手機開熱點，電腦與學生都連這個熱點。
- **控制台出現多個網路介面**：換下拉選單中的另一個位址，QR Code 會跟著換。
- **想換埠號**：`PORT=9000 node server.js`
